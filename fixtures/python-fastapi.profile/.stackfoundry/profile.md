# Orders API: repo profile

## The product

An API that lets signed-in customers read their own orders. A gateway authenticates the customer and passes their
id in `X-Customer-Id`.

## What is at stake

Personal data: one customer must never see another's orders.

## Working agreements

- Git: writes only when the user asks (enforced by guards.json).
- Generated code: `app/generated/**`, regenerated by `python -m app.codegen`; never hand-edited.
- Docs root: `docs`. Specs in `docs/specifications/` are the first oracle.
